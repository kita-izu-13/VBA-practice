## レベル<br>
Lebel1　セルA1に「こんにちは！」を表示<br>
Level2　セルB2に「８５」を表示する、判定メッセージ、「Level2 完了！」表示<br>
Lebel3　ボタンをクリックして、処理を実行<br>
Lebel4　フォーム入力で追加<br>
Level5　重複チェック（同じものは追加しない）<br>
Level6　リストの合計を出す<br>
Level7　ランダム抽選<br>
Level8　複数人ランダム抽選＋履歴管理<br>
Level9　リスト検索<br>
Level10　部分一致検索<br>
Level11　重複チェック（登録前チェック）<br>
Level12　別シート操作<br>
Level13　条件付きコピー<br>
Level14　複数条件で抽出（AND / OR）<br>
Level15　ミニツール作成（総合）<br>

## 苦労や学び<br>
実践しながら知識を覚えるスタイルで学習していきました。<br>
そのため、まずコードを書いて実行してイメージをつかんでから、<br>
コードの内容を確認していきました。<br>
基礎知識を身につけながら、別で実践的なものを作成して、<br>
基礎で使ってないものをまた覚えていくようにしていきました。<br>
それぞれが復習のようなものになり、また実践的なものも作成でき、楽しく学習できました。<br>
新しくできることが増えれば、さらにやりたいこともでき、<br>
さらに難しいこともしたい気持ちがでてきたので、今後も引き続き学習していきたいと思いまいます！<br>
